### 📝 改进内容

#### 1. v0 文件头部新增了完整的概念说明

**新增内容包括：**

1. **CuTe 是什么？**
   - 核心理念：类型系统、编译期计算、零开销抽象

2. **Int<N> vs int 的详细解释**
   ```cpp
   int n = 8;              // 运行时变量
   Int<8> n_compile{};     // 编译期常量
   ```
   - 为什么使用编译期常量
   - 带来的优化好处（循环展开、寄存器优化、立即数指令等）

3. **Shape 和 Stride 的直观解释**
   - Shape: 用"户型图"类比 - 告诉你有几间房，每间多大
   - Stride: 用"门牌号规则"类比 - 告诉你门牌号要加多少
   - Layout = Shape + Stride 的组合

4. **为什么需要 Layout 抽象？**
   - 没有 Layout：手写偏移计算，容易出错
   - 有了 Layout：统一接口，编译期优化

5. **可视化示例**
   - 4×8 矩阵的 row-major 和 column-major 布局
   - 用 ASCII 图展示内存排布和逻辑视图
   - 具体的坐标映射计算示例
